# 歡樂數學加減法大冒險 (幼稚園大班 ~ 國小六年級)

專為 **幼稚園大班至國小六年級** 設計的數學加減法練習與動態互動教學系統。

---

## 🌟 核心特色與符合規格

1. **加減法自由切換**：
   - UI 提供清晰的「➕ 加法」與「➖ 減法」按鈕。
   - **預設為減法練習**。

2. **題目項目數彈性設定 (下拉選單)**：
   - 採用直覺的下拉選單提供選擇。
   - 預設為 **2 個數字**（例如：`72 - 18`、`22 + 33`）。
   - 可切換為 **3 個數字**（例如：`22 + 33 + 57`）或 **4 個數字**（例如：`81 - 61 - 9 - 2`）。
   - 減法題目智慧演算，確保結果不為負數，符合國小教學常規。

3. **位數自由設定 (下拉選單)**：
   - 採用直覺的下拉選單提供選擇。
   - **1 位數**：例如 `9 - 2`、`4 + 3`（適合大班~小一）
   - **2 位數 (預設)**：例如 `72 - 18`、`13 + 69`（適合小一~小二）
   - **3 位數**：例如 `369 + 736`、`852 - 418`（適合小三~小六）
   - **不限 (1~3位數皆可)**：進階跨年級混合挑戰

4. **Flash 風格教學動畫（運算過程可視化）**：
   - **觸發條件**：僅在 **2 個項目且數字皆在 10 以內** 的情境下自動啟動（例如 `8 - 5`、`7 - 3` 或 `4 + 3`）。
   - **版面配置**：動畫展示舞台**佔據整個 UI 55% 以上的區域**（符合至少一半的規格要求）。
   - **跨平台與 Android/Sony 手機語音相容性強化**：
     - 深度相容 Android（如 Sony Xperia、Samsung）、iOS（iPhone/iPad）與桌面瀏覽器。
     - 支援 Google Speech Services 繁體中文語音標籤（相容 `cmn-Hant-TW`、`cmn-TW`、`zh-TW`）。
     - 修復 Android Chrome 非同步 cancel 競爭與記憶體回收 (GC) 造成教學動畫朗讀無聲問題。
     - 算式中的 `－` 發音為「**減**」，`＋` 發音為「**加**」，`＝` 發音為「**等於**」（例如 `8 - 5 = 3` 唸作「8 減 5 等於 3」，不再唸成橫線）。
   - **兩階段引導式教學（不提前爆雷答案）**：
     - **第 3 步（引導思考）**：提問「8 減 5 剩下幾個呢？請數數看！」，畫面上保留未畫叉的物件並標記問號，**絕不提前顯示或唸出答案數字**，引導小朋友觀察與在右側輸入。
     - **第 4 步（公布答案）**：正式揭曉答案「公布答案！剩下 3 個！8 減 5 等於 3！」，並播放勝利慶祝音效與計數徽章。
     - 若小朋友在右側輸入區提前作答送出，系統也會同步解鎖公布答案並慶祝！
   - **豐富 Flash 動畫特色**：
     - 具體物體計數（🍎蘋果、⭐星星、🍬糖果、🏀籃球等 4 種主題可切換）。
     - 減法動態「拿走與畫斜線 ❌」特效、加法動態「合體聚集」特效。
     - 具備播放、暫停、重播、上一步、下一步與慢速撥放控制條。

5. **出題方式靈活切換**：
   - **自動產生 (🎲)**：點擊「換下一題」隨機出題。
   - **手動輸入 (✏️)**：可自由輸入想要練習的數字，且支援「一鍵體驗 10 以內教學動畫」快速示範。

6. **支援「🎙️ 語音辨識輸入答案」與「預設直接允許麥克風權限」**：
   - **預設直接允許麥克風存取**：頁面啟動與首次互動時主動發起麥克風權限預先授權（並於 HTML 標頭宣告 `Permissions-Policy: microphone=*`），避免答題時臨時跳出授權打斷作答節奏。
   - **阿拉伯數字 (0~10) 優先策略**：語音辨識多候選結果全面以 0~10 阿拉伯數字為最高優先權（Priority 1），並加入 JSGF 語音辨識語法權重提示。
   - **卷舌／不捲舌與近音同音字智慧校正**：
     - 若說「4」或「等於4」，語音辨識成「是」或「等於是」時，自動精準辨識為數字 **`4`**。
     - 若說「3」或「等於3」，語音辨識成「山」或「等於山」時，自動精準辨識為數字 **`3`**。
     - 完整涵蓋 0~10 的常見捲舌/不捲舌（zh/ch/sh vs z/c/s）及生活近音詞庫（如「石/時/實」-> 10、「林」-> 0、「陸/溜」-> 6、「期/漆」-> 7、「爸/吧」-> 8 等）。
   - 點擊「🎙️ 語音答題」按鈕後，即可直接對著手機或電腦說出答案（例如說：「3」、「五」、「等於八」或「十二」）。
   - 智慧自然語言解析器自動轉換中文數字、阿拉伯數字與常見口語詞句。
   - 辨識成功後自動填入輸入框並即時對答案，兼顧幼童與觸控操作體驗！

7. **教學動畫與答案輸入智慧聯動**：
   - **第三步自動切換指標**：在 10 以內的簡易運算教學動畫展示中，當動畫播放進行到或進行過「第三步」（或第四步）時，系統會自動將游標焦點（指標）精準切換至右側的「答案輸入框」，並帶有柔和的脈衝醒目動畫，引導學生即時作答。
   - **手動輸入無鍵盤干擾模式**：當選擇「✏️ 手動輸入」出題且指標位於答案輸入框時，自動啟用 `inputmode="none"` 並隱藏網頁虛擬數字鍵盤，完全不顯示手機預設軟體鍵盤或任何虛擬鍵盤介面，徹底解決手機螢幕被彈出鍵盤遮擋動畫的問題。

8. **豐富的學習輔助工具**：
   - 針對 2 位數與 3 位數，提供「**📐 直式算則解析**」（進位與借位輔助解說）。
   - 虛擬觸控數字鍵盤，支援平板與觸控螢幕操作。
   - 連勝火焰、累計得分、歷史答題紀錄清單。

## 🚀 如何啟動使用

### 方法一：直接雙擊開啟（推薦）
在檔案總管中進入 `D:\!Google_AI_Tool\Practice_Math` 資料夾，直接**雙擊 `index.html`**，即可使用任何瀏覽器（Chrome、Edge、Safari 等）開啟使用！

### 方法二：透過本機 HTTP 伺服器
在命令提示字元或 PowerShell 中輸入：
```bash
cd D:\!Google_AI_Tool\Practice_Math
python -m http.server 8080
```
然後在瀏覽器網址列輸入 `http://localhost:8080` 即可使用。
